# MerchantFlow — Usability test protocol

**Status:** Prepared, not yet conducted.

## Task scenario
You operate a small ecommerce fulfillment team. You have 60 seconds to find the order most urgently needing investigation, explain why, and mark it Reviewing.

## Moderator script
1. Ask participant to describe what they expect from the home screen.
2. Start timer and read task exactly as written.
3. Do not provide navigation hints.
4. Stop timer when participant identifies an order and provides a reason.
5. Ask: Which alert was confusing? What action would you take next? What information is missing?

## Record per participant
Participant code (not real name), consent, date, device, task success, time in seconds, chosen order, correct reason, observed confusion, direct quotes (with consent), and suggested improvements.

## Analysis
Report median task time, success rate and common themes. Separate observations from interpretations. Do not invent interviews, findings or outcomes.

## Release decision
Revise UI if fewer than 4 of 5 participants identify the intended priority or if explanation comprehension is poor.
